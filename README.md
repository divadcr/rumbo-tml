# Rumbo a Tomorrowland · FAQ

Preguntas frecuentes del grupo de WhatsApp "Rumbo a TML", que ayuda a quienes van a Tomorrowland Bélgica 2027 por primera vez. Es un proyecto de la comunidad, **no oficial**.

## Contenido

- `index.html` — prototipo de la página en un solo archivo, sin dependencias. Basta con abrirlo en el navegador.
- `faq.json` — las preguntas y respuestas (45, en 8 categorías). Es la fuente de datos para la futura web. Cada respuesta es un fragmento de HTML.
